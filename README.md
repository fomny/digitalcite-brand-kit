# DigitalCite — brand kit and social media

**DigitalCite** is an AI visibility (GEO) platform for the Gulf and Arab markets. It asks the AI engines (ChatGPT, Gemini and Perplexity) the questions buyers really type, in Arabic dialects and in English, then shows who gets named, which sources earned the credit, and what to fix.

- Platform: [digitalcite.com/en/platform](https://digitalcite.com/en/platform) · Pricing: [digitalcite.com/en/pricing](https://digitalcite.com/en/pricing)
